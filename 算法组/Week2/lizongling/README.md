* 注：图片均来源于摄图网

核心算法理解：
HSV阈值：提取特定颜色，根据颜色上下限将目标颜色变成白色，其他背景颜色变为黑色。
轮廓面积筛选：过滤掉背景碎小干扰物，保留面积足够大的目标物
中心点计算：中心点仅代表目标在图像上的像素位置，由于存在透视核镜头畸变，不代表机器人的真实物理世界坐标

## ROS2通信设计说明
- **消息字段设计**：
  在 `my_interfaces` 包中自定义了 `TargetPosition.msg`，包含 4 个字段：
  - `bool detected`：本帧是否检测到目标
  - `float32 u`：目标中心的图像横坐标（像素）
  - `float32 v`：目标中心的图像纵坐标（像素）
  - `float32 area`：目标轮廓面积
- **话题名**：`/target_position`
- **发布/订阅流程**：
  1. **发布节点 (`publisher.py`)**：订阅定时器（1秒触发一次），读取图片并执行 OpenCV 视觉检测逻辑。将检测到的坐标和面积打包成 `TargetPosition` 消息对象，通过 `self.publisher_.publish(msg)` 发布。
  2. **订阅节点 (`subscriber.py`)**：监听 `/target_position` 话题。收到消息后，通过 `if msg.detected:` 判断有效性，并在终端打印 `u, v, area`。
